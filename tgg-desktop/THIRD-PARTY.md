# Git for Windows

The Windows installer includes unmodified MinGit 2.56.0.2, downloaded from the official Git for Windows release:
https://github.com/git-for-windows/git/releases/tag/v2.56.0.windows.2

The original LICENSE.txt and usr/share/licenses and ucrt64/share/licenses directories are retained in the installed mingit resource directory. Git and components retain their upstream licenses; the desktop application's license does not replace those licenses.

Corresponding upstream Git source and build recipes:
https://github.com/git-for-windows/git/tree/v2.56.0.windows.2
https://github.com/git-for-windows/build-extra
https://github.com/git-for-windows/MINGW-packages
https://github.com/git-for-windows/MSYS2-packages
