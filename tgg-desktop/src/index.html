KEEP YOUR WORK RECOVERABLE
Recovery & checks
Metadata backups, project edit recovery, and verified Source bundle restores.

    
Prepared update
Run your quiet updater to build the preview. It puts installers in Downloads → TGG Updates. This checks the completed local build's checksum; it does not verify a publisher signature. Unsigned Windows warnings may appear.
Save work first. After opening the installer, close TGG normally before continuing installation. Existing project data is kept.

    
Startup checks
Checks the owner data and required app files. This is not a publisher signature check or automatic installer rollback.

    
Owner data backup
Includes provider settings, saved chats, app paths and project shortcuts. Restore on this computer with the same Windows account and OS encryption. Source repositories and project files need their own backups.
Restoring replaces current owner settings and locks the app. A previous valid metadata copy is retained.

    
Undo a recorded project edit
Studio saves and applied agent proposals retain an encrypted before-copy. Open the original project; recovery refuses to overwrite a file changed since that edit.

    
Source bundle recovery
Verify a .bundle backup by cloning into a temporary repository and checking Git integrity. Restore creates a new repository, preserving existing repositories and working projects.
